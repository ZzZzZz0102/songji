# 松溉古镇网站

本版移除了 VR 全景页面、导航、嵌入播放器与相关按钮，整站文件总大小小于 25,000,000 字节。

解压整个文件夹后，直接打开 `index.html`。请保持 `assets` 文件夹及 JS、CSS 文件与入口页的相对位置。

保留功能：

- 首页古镇视频自动静音、循环播放，可手动暂停。
- 51 张实景照片、景点介绍、美食、传统手艺、参考选品与购物袋。
- 游览路线、二维码智慧导览、出行服务与外部民宿平台入口。
- 自选游线、预约及购买意向、游客意见、本机管理台账。
- 数字底座、直播助农展示与结算台账、智能 Agent 本地资料查询。

首页与直播助农的实景回放共用压缩后的视频，提供 WebM 与 MP4 两种格式以兼容不同浏览器。首页保持完整约 26 秒时长，尺寸为 1920 x 1062、30 帧/秒。照片保持原构图并进行了尺寸与编码压缩。

智慧导览、地图检索与民宿平台是外部服务，需要联网。本站的意向和台账数据保存在当前浏览器，不提供真实支付、正式预约、跨设备同步或大模型接口；“直播助农”未配置直播链接时显示实景回放。

图片原始来源见 `图片来源清单.md`、`assets/photos/credits.json` 与 `assets/photos/food-credits.json`。压缩不改变图片来源与版权归属。
